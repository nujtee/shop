# Phasakura Shop

ร้านค้าออนไลน์ของ Phasakura ที่ shop.phasakura.com ทำงานบน Cloudflare Workers ใช้ D1 เป็นฐานข้อมูล และ R2 เก็บรูปสินค้ากับสลิป

## มีอะไรบ้าง

**หน้าร้าน**

- หน้าแรก: ค้นหา, แท็บหมวดหมู่, เรียงลำดับ (แนะนำ / ขายดี / มาใหม่ / ราคา), ตัวกรอง (ลดราคา, พร้อมส่ง, ช่วงราคา), แถบโปรโมชันนับถอยหลัง, การ์ดสินค้า 2 คอลัมน์บนมือถือ
- หน้าสินค้า: รูปหลายรูปแบบเลื่อน, ตัวเลือก (ขนาด/ชุด) ที่มีราคาและสต็อกแยก, ราคาก่อนลด, ปุ่มแชท LINE
- ตะกร้าและชำระเงิน: ไม่ต้องสมัครสมาชิก, คูปอง, ค่าส่งตามน้ำหนัก, ส่งฟรีเมื่อครบยอด
- ชำระเงิน 2 แบบ: **พร้อมเพย์** (QR พร้อมยอดเงิน แล้วลูกค้าแนบสลิป) และ **เก็บเงินปลายทาง** (มีค่าบริการได้)
- หน้าติดตามคำสั่งซื้อ: สถานะ เลขพัสดุ และค้นหาด้วยเลขออเดอร์ + เบอร์โทรที่ `/track`

**หลังบ้าน** (`/admin`)

- ภาพรวม: ยอดขายวันนี้, ยอด 7 วัน, สลิปรอตรวจ, ออเดอร์รอแพ็ค, สินค้าใกล้หมด
- คำสั่งซื้อ: ดูสลิป, ยืนยันรับเงิน, แพ็ค, ใส่เลขพัสดุ, ยกเลิก (คืนสต็อกอัตโนมัติ), พิมพ์ใบปะหน้า A6
- สินค้า: เพิ่ม/แก้/ซ่อน, ตัวเลือก ราคา สต็อก น้ำหนัก, อัปโหลดรูป (ย่อรูปอัตโนมัติ)
- สต็อก: ปรับเข้า/ออกพร้อมเหตุผล, ประวัติการเปลี่ยนแปลง
- หมวดหมู่, คูปอง (ลด % / ลดบาท / ส่งฟรี), ตั้งค่าร้าน (พร้อมเพย์, ค่าส่ง, แถบโปร, นโยบาย)

**อัตโนมัติ**

- แจ้งเตือนเข้า LINE เมื่อมีออเดอร์ใหม่และเมื่อลูกค้าแนบสลิป
- ตัดสต็อกตอนสั่งซื้อ ถ้าไม่แนบสลิปภายในเวลาที่ตั้ง (ค่าเริ่มต้น 24 ชม.) ระบบยกเลิกและคืนสต็อกให้ (ตรวจทุก 30 นาที)

## ติดตั้งขึ้น Cloudflare

สร้างไว้แล้ว (18 พ.ย. 2026):

- Worker ชื่อ `shop` (ตรงกับ `name` ใน `wrangler.jsonc`)
- ฐานข้อมูล D1 `phasakura-shop` พร้อมตารางทั้งหมด (migration 0001)
- ที่เก็บรูป R2 `phasakura-shop-media`

ที่ต้องทำเองใน Cloudflare dashboard → Workers & Pages → `shop` → Settings → Variables and Secrets (เลือกแบบ Secret):

| ชื่อ | ค่า |
| --- | --- |
| `ADMIN_PASSWORD` | รหัสเข้าหลังบ้าน |
| `SESSION_SECRET` | ข้อความสุ่มยาว 32 ตัวขึ้นไป |
| `LINE_CHANNEL_ACCESS_TOKEN` | จาก LINE Developers (ดูด้านล่าง) |
| `LINE_NOTIFY_TO` | User ID ของคุณใน LINE (ขึ้นต้นด้วย U) |

ขึ้นเว็บ: ถ้า Worker `shop` ต่อกับ repo นี้ผ่าน Workers Builds แล้ว แค่ merge เข้า `main` ก็ deploy ให้เอง ไม่อย่างนั้นรัน

```bash
npm install
npx wrangler login
npm run db:migrate   # ใช้เมื่อมี migration ใหม่เท่านั้น
npm run deploy       # ผูกโดเมน shop.phasakura.com ให้อัตโนมัติ
```

จากนั้นเข้า `https://shop.phasakura.com/admin` แล้วไปที่ **ตั้งค่าร้าน** เพื่อใส่เลขพร้อมเพย์และตารางค่าส่ง

### ค่า LINE มาจากไหน

ใน [LINE Developers Console](https://developers.line.biz/console/) เลือก Messaging API channel ของ LINE OA ร้าน

- `LINE_CHANNEL_ACCESS_TOKEN`: แท็บ Messaging API → Channel access token (long-lived) → Issue
- `LINE_NOTIFY_TO`: แท็บ Basic settings → Your user ID (ต้องเป็นเพื่อนกับ LINE OA ร้านก่อน) ใส่หลายคนคั่นด้วยจุลภาคได้

## พัฒนาในเครื่อง

```bash
cp .dev.vars.example .dev.vars   # ใส่รหัสผ่านทดสอบ
npm run db:migrate:local
npm run db:demo                  # ข้อมูลตัวอย่าง (เฉพาะในเครื่อง)
npm run dev                      # http://localhost:8787
npm run typecheck && npm test
```

## โครงสร้าง

```
src/index.tsx          จุดเริ่ม, ความปลอดภัย, งานตั้งเวลา
src/routes/shop.tsx    หน้าร้าน, หน้าสินค้า, ตะกร้า, ออเดอร์, สลิป
src/routes/api.ts      คำนวณราคา และสร้างออเดอร์
src/routes/admin.tsx   หลังบ้านทั้งหมด
src/lib/store.ts       ค่าส่ง, คูปอง, ตัดสต็อก, ยกเลิกออเดอร์
src/lib/promptpay.ts   QR พร้อมเพย์ (EMVCo)
src/lib/line.ts        แจ้งเตือน LINE
migrations/            โครงสร้างฐานข้อมูล
public/                CSS และ JavaScript ฝั่งเบราว์เซอร์
```

เงินทุกช่องในฐานข้อมูลเก็บเป็นสตางค์ เวลาเก็บเป็น UTC และแสดงเป็นเวลาไทย
